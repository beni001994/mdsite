This site is the `example/` directory of the **mdsite** repository. It exists
to exercise the generator: posts, tags, drafts, a page with navigation, and a
feed.

Build it with:

```sh
npm run example
```

Pages without a `date` (like this one) appear in the navigation instead of the
post list.
