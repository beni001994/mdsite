---
title: Getting started with mdsite
date: 2025-01-20
tags: [meta, tutorial]
---

1. Create a folder with `content/` and an optional `mdsite.json`.
2. Run `mdsite new "My first post"` to create a draft.
3. Run `mdsite build`, or `mdsite serve` to preview with rebuilds on change.

Everything under `static/` is copied as-is into the output.
